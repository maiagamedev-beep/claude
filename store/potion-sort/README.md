# Potion Sort

**Type:** 2D · Sort puzzle · **Mobile:** yes (touch controls) · **Made with AI:** yes · **Upload:** `dist/potion-sort.zip`

## Description (EN)
Pour colored potions between flasks until every flask holds one color. 100 levels on an alchemist shelf.

## How to play (EN)
Tap a flask, then another, to pour the top color. You can only pour onto the same color or into an empty flask. Sort each color into its own flask.

## Descrição (PT)
Despeje poções entre frascos até cada um ter uma só cor. 100 fases numa prateleira de alquimista.

## Como jogar (PT)
Toque num frasco e depois em outro para despejar a cor de cima. Só dá para despejar sobre a mesma cor ou num frasco vazio. Separe cada cor no seu frasco.
