# Planet Merge

**Type:** 2D · Merge physics · **Mobile:** yes (touch controls) · **Made with AI:** yes · **Upload:** `dist/planet-merge.zip`

## Description (EN)
Drop space bodies into the jar; two equal ones merge into the next — from pebble to Earth to the Sun.

## How to play (EN)
Move and tap/click (or arrows + Space) to drop a body into the jar. Two equal bodies merge into the next one: pebble → moon → … → Earth → … → Sun. Do not let the jar overflow.

## Descrição (PT)
Solte astros no pote; dois iguais se fundem no próximo — da pedrinha à Terra até o Sol.

## Como jogar (PT)
Mova e toque/clique (ou setas + Espaço) para soltar um astro no pote. Dois iguais se fundem no próximo: pedra → lua → … → Terra → … → Sol. Não deixe o pote transbordar.
