# Helix Drop

**Type:** 3D · Arcade · **Mobile:** yes (touch controls) · **Made with AI:** yes · **Upload:** `dist/helix-drop.zip`

## Description (EN)
Spin the tower so the bouncing ball falls through the gaps. Avoid red zones, drop through three floors to become a fireball. 100 levels.

## How to play (EN)
Drag left/right (or use the arrow keys) to spin the tower. Let the ball drop through the gaps. Never land on red. Fall through 3 floors in a row to become a fireball that smashes anything.

## Descrição (PT)
Gire a torre para a bola cair pelos buracos. Evite as zonas vermelhas, passe três andares para virar bola de fogo. 100 fases.

## Como jogar (PT)
Arraste para os lados (ou use as setas) para girar a torre. Deixe a bola cair pelos buracos. Nunca caia no vermelho. Passe 3 andares seguidos para virar uma bola de fogo que quebra tudo.
