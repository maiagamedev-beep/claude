# Color Gate

**Type:** 2D · Arcade · **Mobile:** yes (touch controls) · **Made with AI:** yes · **Upload:** `dist/color-gate.zip`

## Description (EN)
Hop through spinning gates only where the color matches yours. Switch colors with rainbow orbs.

## How to play (EN)
Tap or press Space to hop up. You can only pass through parts of a gate that match your color. Touch the rainbow orb to change color. Collect the star inside every gate.

## Descrição (PT)
Pule pelos portais giratórios só onde a cor combina com a sua. Troque de cor nas esferas arco-íris.

## Como jogar (PT)
Toque ou aperte Espaço para pular. Você só atravessa as partes do portal da sua cor. Toque na esfera arco-íris para mudar de cor. Pegue a estrela dentro de cada portal.
