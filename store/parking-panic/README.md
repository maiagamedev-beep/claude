# Parking Panic

**Type:** 2D · Parking jam · **Mobile:** yes (touch controls) · **Made with AI:** yes · **Upload:** `dist/parking-panic.zip`

## Description (EN)
Swipe cars out of a jammed lot. Every lot is checked solvable. 60 levels.

## How to play (EN)
Swipe a car forward or backward along its lane (or tap to drive where its nose points). It leaves the lot if nothing is in the way. Clear every car in as few moves as you can.

## Descrição (PT)
Deslize carros para fora de um estacionamento travado. Todos são verificados como solucionáveis. 60 fases.

## Como jogar (PT)
Deslize um carro para frente ou para trás na direção dele (ou toque para ir para onde o bico aponta). Ele sai se nada estiver no caminho. Libere todos com o mínimo de jogadas.
