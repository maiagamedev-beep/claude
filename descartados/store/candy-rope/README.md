# Candy Rope

**Type:** 2D · Physics puzzle · **Mobile:** yes (touch controls) · **Made with AI:** yes · **Upload:** `dist/candy-rope.zip`

## Description (EN)
Cut ropes, pop bubbles and swing the candy into the frog. Levels are generated from a simulated solution so every one is solvable.

## How to play (EN)
Swipe across a rope to cut it. Swing the candy so it falls into the frog’s mouth, grabbing the stars on the way. Tap a bubble to pop it. Avoid the thorny vines.

## Descrição (PT)
Corte cordas, estoure bolhas e balance o doce até o sapo. As fases são geradas a partir de uma solução simulada, então todas têm solução.

## Como jogar (PT)
Deslize sobre uma corda para cortá-la. Balance o doce para ele cair na boca do sapo, pegando as estrelas no caminho. Toque na bolha para estourar. Evite os espinhos.
