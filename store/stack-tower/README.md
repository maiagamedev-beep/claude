# Stack Tower

**Type:** 3D · Stacking · **Mobile:** yes (touch controls) · **Made with AI:** yes · **Upload:** `dist/stack-tower.zip`

## Description (EN)
Drop sliding slabs to build the tallest tower. Perfect drops chain and grow the slab back. Minimal pastel 3D with 7 themes.

## How to play (EN)
Tap, click or press Space to drop the sliding slab. Whatever hangs over is cut off. Land it perfectly to keep its size — 4 perfects in a row make it grow back.

## Descrição (PT)
Solte blocos deslizantes para construir a torre mais alta. Encaixes perfeitos encadeiam e fazem o bloco crescer. 3D minimalista em tons pastel com 7 temas.

## Como jogar (PT)
Toque, clique ou aperte Espaço para soltar o bloco. O que sobrar para fora é cortado. Acerte em cheio para manter o tamanho — 4 perfeitos seguidos fazem ele crescer.
