# Fruit Orchard

**Type:** 2D · Match-3 · **Mobile:** yes (touch controls) · **Made with AI:** yes · **Upload:** `dist/fruit-orchard.zip`

## Description (EN)
Swap watercolor fruits to match three or more across 60 levels with score, collect and jelly goals. Build striped fruits, bombs and rainbows for huge cascades.

## How to play (EN)
Swap neighbouring fruits to line up 3 or more. Match 4 for a striped fruit, L/T shapes for a bomb, 5 in a row for a rainbow. Reach the level goal before you run out of moves.

## Descrição (PT)
Troque frutas em aquarela para juntar três ou mais em 60 fases com metas de pontos, coleta e geleia. Crie frutas listradas, bombas e arco-íris para cascatas enormes.

## Como jogar (PT)
Troque frutas vizinhas para alinhar 3 ou mais. 4 fazem uma fruta listrada, formatos L/T fazem uma bomba, 5 em linha fazem um arco-íris. Cumpra a meta antes de acabar as jogadas.

## Rewarded video placements (always optional)
+5 moves, free boosters, x2/x3 coins; plus the shared meta systems below.

Every game also has a daily login calendar, a lucky wheel (free every 4h + optional video spins), a free gift every 8 minutes, 3 daily missions with rerolls, player level with chests and cloud save.

Interstitials (`midgame`) are only requested after a game over / level end, when the player presses the restart or next button, and never more than once every ~2 minutes.
