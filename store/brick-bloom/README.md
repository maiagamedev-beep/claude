# Brick Bloom

**Type:** 2D · Balls vs bricks · **Mobile:** yes (touch controls) · **Made with AI:** yes · **Upload:** `dist/brick-bloom.zip`

## Description (EN)
Aim and fire a volley of balls at numbered bricks that step down every turn. Collect rings for more balls.

## How to play (EN)
Drag to aim and release to fire all your balls (or arrows + Space). Each hit takes one point off a brick. Collect green rings for extra balls. Bricks move down every turn — do not let them reach the bottom.

## Descrição (PT)
Mire e dispare uma rajada de bolas nos tijolos numerados que descem a cada rodada. Pegue anéis para mais bolas.

## Como jogar (PT)
Arraste para mirar e solte para disparar todas as bolas (ou setas + Espaço). Cada batida tira um ponto do tijolo. Pegue anéis verdes para ganhar bolas. Os tijolos descem a cada rodada — não deixe chegarem embaixo.
