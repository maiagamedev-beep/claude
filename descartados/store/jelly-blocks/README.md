# Jelly Blocks

**Type:** 2D · Block puzzle · **Mobile:** yes (touch controls) · **Made with AI:** yes · **Upload:** `dist/jelly-blocks.zip`

## Description (EN)
Drag glossy jelly pieces onto an 8×8 board and clear rows and columns. Endless classic mode plus 40 adventure levels that free trapped gems.

## How to play (EN)
Drag the pieces onto the board. Fill a whole row or column to clear it. Clearing several lines at once or in a row builds combos. The game ends when no piece fits. In Adventure, clear the lines holding gems.

## Descrição (PT)
Arraste peças de gelatina para um tabuleiro 8×8 e limpe linhas e colunas. Modo clássico infinito e 40 fases de aventura para libertar gemas.

## Como jogar (PT)
Arraste as peças para o tabuleiro. Complete uma linha ou coluna para limpá-la. Limpar várias linhas de uma vez ou seguidas gera combos. O jogo acaba quando nenhuma peça cabe. No Aventura, limpe as linhas com gemas.

## Rewarded video placements (always optional)
clear the middle to continue, x2/x3 coins; plus the shared meta systems below.

Every game also has a daily login calendar, a lucky wheel (free every 4h + optional video spins), a free gift every 8 minutes, 3 daily missions with rerolls, player level with chests and cloud save.

Interstitials (`midgame`) are only requested after a game over / level end, when the player presses the restart or next button, and never more than once every ~2 minutes.
