# Hexa Stack

**Type:** 2D · Hexa sort · **Mobile:** yes (touch controls) · **Made with AI:** yes · **Upload:** `dist/hexa-stack.zip`

## Description (EN)
Drop stacks of hex tiles; matching colors slide together and 10 on top clear. 50 levels.

## How to play (EN)
Drag a stack from the bottom onto an empty hex. Neighbouring stacks with the same top color slide together. 10 or more tiles of one color on top disappear. Reach the goal before the board fills up.

## Descrição (PT)
Solte pilhas de hexágonos; cores iguais se juntam e 10 no topo somem. 50 fases.

## Como jogar (PT)
Arraste uma pilha de baixo para um hexágono vazio. Pilhas vizinhas com a mesma cor no topo se juntam. 10 ou mais peças da mesma cor no topo somem. Cumpra a meta antes do tabuleiro encher.
