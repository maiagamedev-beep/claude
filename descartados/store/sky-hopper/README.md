# Sky Hopper

**Type:** 2D · Endless jumper · **Mobile:** yes (touch controls) · **Made with AI:** yes · **Upload:** `dist/sky-hopper.zip`

## Description (EN)
Bounce up a graph-paper sky on platforms, springs and rockets; stomp cloud monsters.

## How to play (EN)
Move left/right with the arrow keys/A-D, or hold/drag where you want to go. Bounce on platforms to climb, use springs and rockets, stomp cloud monsters from above. Crumbly ledges break!

## Descrição (PT)
Pule por um céu de caderno quadriculado em plataformas, molas e foguetes; pise em monstros-nuvem.

## Como jogar (PT)
Mova com as setas/A-D, ou segure/arraste para onde quer ir. Pule nas plataformas para subir, use molas e foguetes, pise nos monstros-nuvem por cima. Plataformas rachadas quebram!

## Rewarded video placements (always optional)
rocket rescue, x2 coins; plus the shared meta systems below.

Every game also has a daily login calendar, a lucky wheel (free every 4h + optional video spins), a free gift every 8 minutes, 3 daily missions with rerolls, player level with chests and cloud save.

Interstitials (`midgame`) are only requested after a game over / level end, when the player presses the restart or next button, and never more than once every ~2 minutes.
